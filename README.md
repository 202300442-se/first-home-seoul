# 첫 자취, 서울

서울에 처음 집을 구하는 대학생, 특히 여성 1인 가구가 예산과 지역 정보를 함께 비교하도록 돕는 정적 웹사이트입니다.

- 공개 주소: https://202300442-se.github.io/first-home-seoul/
- 저장소: https://github.com/202300442-se/first-home-seoul
- 제작: 김시은 / 한국외대 융합일본지역전공 3학년
- 현재 상태(2026-10-07): 실제 API 계약 1,729건(2026-07~09) 수집 및 배포 완료. 기본 조건 월세 731건. 파서·집계 테스트 7개 통과. 공개 사이트에서 필터·전세 전환·빈 결과·잘못된 범위·범죄 통계·페이지 이동·체크 저장·390/768/1440px 화면 검증 완료.

## 기능

동대문구·성북구·중랑구 오피스텔 실거래가를 보증금 범위, 월세 상한, 면적, 신규/갱신 계약으로 필터링합니다. 조건에 맞는 계약 수와 중앙값을 비교하고, 실제 계약을 정렬·페이지 이동하여 확인할 수 있습니다. 전세와 월세는 구분합니다. 2024년 구별 범죄 통계는 가격 필터와 독립적으로 표시합니다. 집 방문 체크리스트는 브라우저 localStorage에만 저장합니다.

## 출처와 해석

- 국토교통부 오피스텔 전월세 실거래가: https://www.data.go.kr/data/15126475/openapi.do (이용허락범위 제한 없음)
- 경찰청 범죄 발생 지역별 통계 2024: https://www.data.go.kr/data/3074462/fileData.do
- 범죄 원본 CSV: data/crime-2024.csv. 공개 원본 파일을 보존하고 범죄대분류별로 중분류를 합산합니다.
- 원본 다운로드: https://www.data.go.kr/cmm/cmm/fileDownload.do?atchFileId=FILE_000000003561346&fileDetailSn=1&insertDataPrcus=N
- 결합 기준: 법정 시군구코드 11230(동대문구), 11290(성북구), 11260(중랑구)와 범죄 CSV의 해당 자치구 열.
- 가격: 빌드 시점 직전 완료된 3개월(2026-10 빌드 시 2026-07~09). 범죄: 2024년 고정 통계. 시간 범위가 다르므로 인과관계 분석이 아닙니다.
- API 페이지를 끝까지 조회하고 전체 건수를 대조합니다. 신규·갱신을 모두 포함하며 필터로 구분할 수 있습니다. 서로 다른 계약이 같은 값일 수 있어 임의로 중복 제거하지 않습니다.
- 보증금·월세 단위는 만원, 면적은 ㎡. 월세 0원은 전세로 구분합니다. 중앙값은 홀수 건의 가운데 값, 짝수 건의 가운데 두 값 평균입니다.
- 관리비·공과금, 현재 매물 여부, 방 개수는 제공하지 않습니다. 오피스텔을 원룸으로 단정하지 않습니다.
- 범죄 수치는 발생 건수이며 인구·유동인구 보정, 피해자 성별 구분, 골목·건물별 위험 추정은 하지 않습니다. 안전 등급과 순위를 만들지 않습니다.
- 신고 지연과 정정으로 거래가 바뀔 수 있습니다. 소표본(5건 미만)은 화면에 표시합니다.

## 실행 / 수정

Python 3.13, 외부 Python 패키지 없이 동작합니다.

```sh
python -m unittest discover -s tests -v
python build.py
```

실제 수집 명령에는 환경 변수 DATA_GO_KR_KEY가 필요합니다. 키를 코드·README·명령 기록에 넣지 마세요. GitHub Actions에서 실행하는 것을 권장합니다. `_site/index.html`을 열면 결과를 볼 수 있습니다.

- 화면: index.template.html
- 디자인: style.css
- 필터·정렬·체크리스트: app.js
- 수집·검증: build.py
- 배포: .github/workflows/site.yml

## 배포와 갱신

Repository Secret DATA_GO_KR_KEY에 일반 인증키(Decoding)를 저장하고 Pages Source를 GitHub Actions로 설정합니다. main에 코드를 push하거나 Actions → First Home Seoul → Run workflow를 누르면 수집·검증 후 배포합니다. README만 수정할 때는 재조회하지 않습니다. 예약 갱신은 설정하지 않았습니다.

API 연결·인증·파싱·페이지 누락 시 빌드를 실패시켜 이전 배포를 유지합니다. 키나 요청 URL을 로그 또는 HTML·JSON에 넣지 않습니다. 모의 데이터를 실제 자료로 대체하지 않습니다. 범죄 CSV는 연간 원본이 변경되면 출처·연도·검증값과 함께 수동 갱신합니다.

## AI 활용

사용자는 대상·문제·지역 범위와 데이터 사용 목적을 결정했고, Codex가 구현과 데이터 연동을 보조했습니다. 출처, 실제 값, 필터, 제한 사항을 검증해 과제에서 설명할 수 있도록 코드를 공개합니다.
